Project Overview

JU Blood Bank is a comprehensive Android application developed to facilitate blood donation within the Jahangirnagar University community.

Built with Kotlin and powered by Firebase, this app serves as a vital bridge between blood donors and recipients in emergency situations.

Key Features:

  • Blood donor search
  • Availability updates
  • User authentication
  • Emergency contacts
  • Donor history & stats
  • Offline synchronization

Tech Stack:

Kotlin Android Studio Firebase Room Database Material Design Google Maps API
